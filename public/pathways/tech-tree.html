    How Pathways works

    Pathways visualizes a climate-action certification or incentive program as a skill tree, like a strategy-game tech tree. Each program is a module; the engine is universal.

  • Left pane tracks your progress: points, milestones, and per-category coverage as you build the pathway.
  • Center canvas is the tree: actions grouped into horizontal lanes by the program's categories, positioned in prerequisite-order columns, with gold connector lines.
  • Right pane is the action dossier: overview, point rules, submission requirements, funding co-benefits. Locked actions list exactly which prerequisites are missing — click a prerequisite to navigate to it — and the full chain is highlighted in violet on the canvas.
  • GHG impact is illustrative. A direct action can carry its own editable maximum annual impact assumption. Pathways prorates that amount by credited points divided by the action's maximum points, clamped from 0% to 100%. No universal point-to-ton conversion is used. Enabling and adaptation actions are not directly quantified, and overlap groups count only their largest estimate.

    • Methodology disclosure: These estimates are for concept planning only. They are not an emissions inventory, a forecast, a claim of achieved reductions, or a DEC-approved accounting method. Replace the rounded defaults with locally supported estimates before using them in planning.

    Adding a program (other states, cities)

    A program module is just JSON conforming to the schema below — no code. Use ＋ Import program to load one, then switch programs from the dropdown in the top bar.

    PROGRAM = {
  "id": "csc-ny",
  "name": "Climate Smart Communities",
  "jurisdiction": "New York State · NYSDEC",
  "source_url": "https://climatesmart.ny.gov",
  "point_floor": 300,          // top certification threshold
  "levels": [
    {"name": "Registered", "min_points": 0, "min_categories": 0},
    {"name": "Bronze",     "min_points": 120, "min_categories": 4},
    {"name": "Silver",     "min_points": 300, "min_categories": 6}
  ],
  "categories": ["PE1", "PE2", ...],   // lane order, left pane
  "category_names": {"PE1": "Build a Climate-Smart Community", ...},
  "tiers": ["I — Foundation", ...],    // column headers
  "actions": [{
      "id": 1, "name": "CSC Pledge", "icon": "📜",
      "tier": 0, "category": "PE1", "points": "4",
      "prereq": [],                  // ids of prerequisite actions
      "tags": ["mandatory"],         // priority | grant | cec | mandatory | perf
      "subgroup": "Governance",      // optional authored semantic theme
      "why": "short hook for the card",
      "details": [ {"title": "...", "points_how": "...", "submit": "...", "timeframe": "...", "recert": "..."} ],
      "lookback": "10 years",        // optional retroactive credit window
      "cobenefits": ["..."],          // optional funding / program synergies
      "impact": {                     // optional, explicit per-action assumption
        "kind": "direct",             // direct | enabling | adaptation
        "max_annual_mtco2e": 500,
        "overlap_group": "municipal-fleet"
      }
  }]
}

    Actions, levels, categories and milestones are all arbitrary per program — a city's incentive checklist or a state adaptation program uses the same engine, its own lanes and its own point scheme.
